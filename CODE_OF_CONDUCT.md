# Code of Conduct

Night Shift follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and give feedback about the work, not the person. Harassment of any kind is not accepted, in issues, pull requests, or any other project space.

## Report a problem

Contact the maintainer, [@xiduzo](https://github.com/xiduzo), at the email address on their GitHub profile. Reports stay private. The maintainer decides what to do, from a warning to a ban from the project.
