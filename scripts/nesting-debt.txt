# Sub-verticals: rules (o) and (p) of scripts/check-verticals.ts.
#
# The rule (o): a folder inside a vertical that has its own index.ts is a
# sub-vertical, at every depth. Code outside it imports it only through
# that barrel. The barrel holds only imports and exports. Every name on it
# has an importer outside the sub-vertical. Tests may deep-import.
#
# The rule (p): a vertical or a sub-vertical with more than 25 source files
# or more than 5,000 lines (tests do not count) consists of sub-verticals.
# Each folder directly in it has an index.ts. Its own code, the files
# directly in it, stays within the same two limits. The ring folders
# domain/, application/, adapters/, adapters/in/ and adapters/out/ need no
# barrel, and their files count as its own code.
#
# This list holds what broke the rules on the day they started. The check
# fails an offender that is not listed, and fails a line once it is clean.
# Do not add a line: fix the new offender. Remove a line in the change
# that fixes it.
#
# A line is one of:
#   <folder>                  a vertical or sub-vertical with too much code
#                             of its own, or a folder with no index.ts in
#                             one that must split (p)
#   <file> -> <sub-vertical>  the file imports past that barrel (o)
#   <barrel> exports <name>   no file outside the sub-vertical imports the
#                             name (o)
#   <barrel> holds code       a statement that is not an import or an
#                             export (o)
